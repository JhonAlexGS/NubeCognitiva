## 👋 Sobre este portafolio
 
De la ingeniería de telecomunicaciones a la nube y la IA. Este repositorio documenta mi camino: desde señales GNSS y SDR hasta modelos de Deep Learning para ciberseguridad industrial, pasando por desarrollo Full Stack y arquitecturas cloud en AWS y Azure.
 
## 🚀 Lo que vas a encontrar aquí
 
- **🛰️ Investigación en señales GNSS** — Publicación IEEE (2023) sobre adquisición de señales GNSS mediante SDR.
- **🛡️ Ciberseguridad industrial** — Sistema de detección de intrusiones para redes SCADA (ModBus TCP/IP) con **99.49% de accuracy**, superando el estado del arte en +15.28 puntos porcentuales. Stack: Python, TensorFlow, scikit-learn, Docker, Raspberry Pi 5.
- **💻 Desarrollo Full Stack** — Proyectos con React, Express.js y arquitecturas API RESTful.
- **☁️ Arquitectura Cloud** — Soluciones sobre AWS (S3, EC2, Lambda, RDS, SageMaker) y Azure.
- **🤖 Arquitecturas multiagente** — Exploración de sistemas de IA colaborativos.
